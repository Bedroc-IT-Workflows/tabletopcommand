Tabletop Command

Built for readiness. Growing toward resilience.

A high-level view of the capabilities available today and the ideas that can take Tabletop Command beyond its minimum viable product.

Direction, not deadlines

Future priorities may change as teams use the platform and new readiness needs emerge.

Complete

MVP foundation

The core workflow needed to plan, run, document, and close an exercise.

  1. Facilitated tabletop exercises

    Run structured scenarios with controlled event reveals, participants, objectives, and an exercise timer.

  2. Decisions and evidence capture

    Record decisions, observations, supporting evidence, owners, and related control areas as the exercise unfolds.

  3. Remediation tracking

    Convert identified gaps into assigned follow-up actions with owners and due dates.

  4. Audit-ready reporting

    Generate editable exercise reports and printable timelines suitable for SOC 2 evidence.

  5. Reusable runbooks

    Create and administer scenario runbooks, events, prompts, and control mappings.

  6. Secure hosted access

    Support Microsoft Entra ID authentication and deployment through Azure Static Web Apps.

Next

Operational depth

Capabilities that turn individual exercises into an ongoing readiness program.

  1. Persistent exercise storage

    Replace manual JSON files with centrally stored drafts, completed exercises, and reports.

  2. Exercise history and dashboard

    Browse previous exercises and see outstanding remediation work across the organization.

  3. Organization profiles

    Maintain reusable teams, roles, business units, and common exercise settings.

  4. Expanded scenario library

    Add continuity, disaster recovery, cloud outage, data breach, vendor compromise, and insider-threat exercises.

Future

Beyond the MVP

High-value ideas for collaboration, insight, automation, and broader delivery.

  1. Real-time collaboration

    Allow facilitators, participants, and observers to contribute simultaneously during an exercise.

  2. Workflow integrations

    Send remediation work to systems such as Jira, Azure DevOps, ServiceNow, or Microsoft Planner.

  3. Evidence attachments

    Attach screenshots, policies, tickets, logs, and other supporting artifacts directly to exercise events.

  4. Readiness analytics

    Compare exercises over time, identify recurring gaps, and measure improvements in control maturity.

  5. AI-assisted exercise design

    Draft scenario events, injects, prompts, and post-exercise summaries from organizational context.

  6. External workspaces

    Support multiple organizations, tenant separation, permissions, and branded client deliverables.

This roadmap is intentionally high level. Detailed defects, maintenance work, and implementation tasks remain in the development backlog.
